# Day 1 — System Foundation

Day 1 gives the base for the four days that come after it. A strong administration setup stops errors later in the workflow.

**Manual chapters:** 1 and 2

## Objectives

After Day 1, the trainees can do these tasks:

- Move through the Tekla PowerFab screen layout.
- Create a user and set the permissions.
- Add a firm and a contact to the **Address Book**.
- Add a shape and a dimension in **Shapes/Grades/Sizes**.
- Add a supplier and a base price in **Pricing Maintenance**.

## Sessions

| Session | Topic | Chapters |
|---|---|---|
| [Morning](morning.md) | System navigation and basic administration | 1.0 thru 2.7 |
| [Afternoon](afternoon.md) | Material libraries and integrations | 2.8 thru 2.12 |

!!! warning
    The afternoon session is the most important part of Day 1. A wrong shape database or a wrong grade database gives wrong results in Estimating, Purchasing and Production Control.
