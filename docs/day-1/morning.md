# Day 1 — Morning Session

- **Topic:** System navigation and basic administration
- **Chapters:** 1.0 thru 2.7

## 1. Tekla PowerFab overview (Chapter 1)

### 1.1 Project workflow

Explain the full workflow before you open any screen. An estimate becomes a project. The project moves through combining and purchasing. The material then goes to the shop floor through **Production Control**.

### 1.2 Screen layout and orientation

1. Show the menu bar: **File**, **Maintenance**, **About** and **Windows**.
2. Show the Navigation Tree, the Display Field and the Input Field.
3. Open one job to show how the Display Field changes.

### 1.3 Customize the grid

1. Right-click the display area.
2. Select **Customize Grid**.
3. Add the columns that the role needs. Remove the other columns.

!!! tip
    Save one grid layout for each role. A short grid keeps the screen simple for a new user.

## 2. Basic administration (Chapters 2.0 thru 2.7)

!!! info
    The manual covers topics 2.1 thru 2.7 in the remote Kick Start Meeting before the training. Ask the trainees what they completed. Review these topics again in short form.

### 2.1 Users and permissions

1. Go to **File > Administration**.
2. Create one user and give the user a password.
3. Set the permissions for Tekla PowerFab Office.
4. Set the remote permissions for Tekla PowerFab Go.

!!! warning
    A user without remote permissions cannot log in to Tekla PowerFab Go. Set the remote permissions for each shop floor user.

### 2.2 Company information and costs

1. Open **Company Information** and add the report logo.
2. Open **Cost Maintenance** and add the cost codes and the cost types.
3. Set the currency.
4. Set the tax rates and the tax groups.

### 2.3 Address Book

1. Open the **Address Book**.
2. Add one firm and one contact.
3. Set the Firm Type, for example Subcontractor or Supplier.

!!! tip
    The Firm Type controls where the firm shows in the other modules. A supplier with the wrong Firm Type does not show in the purchase order list.
