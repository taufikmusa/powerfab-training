## Before the class

1. Install Tekla PowerFab Office on each trainee machine.
2. Make sure that each trainee has a user account and a password.
3. Make sure that each trainee can log in to Tekla PowerFab Go.
4. Restore the training database on the server.
5. Copy the exercise files to a shared folder.

!!! warning
    Do not use a live production database for the training. The trainees make test data that you cannot remove easily.

## Teaching method

Use the **Tell, Show, Do** method for each topic:

1. **Tell** — give the reason for the task.
2. **Show** — do the task one time on the screen.
3. **Do** — let the trainees do the same task.
