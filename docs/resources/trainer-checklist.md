# Trainer Checklist

Use this checklist before the class, during the class and after the class.

## Two weeks before

- [ ] Confirm the trainee list and the roles.
- [ ] Confirm the software version for each machine.
- [ ] Send the Kick Start Meeting invitation for Chapters 2.1 thru 2.7.
- [ ] Ask the customer for a sample model or a sample IFC file.

## One week before

- [ ] Restore the training database.
- [ ] Make one user account for each trainee.
- [ ] Set the remote permissions for Tekla PowerFab Go.
- [ ] Test the Trimble Connect integration.
- [ ] Copy the exercise files to a shared folder.

## On each training day

- [ ] Test the projector and the screen resolution.
- [ ] Log in to Tekla PowerFab Office and Tekla PowerFab Go before the class starts.
- [ ] Show the day objectives at the start.
- [ ] Give a break every 90 minutes.
- [ ] Collect the questions for the last hour.

## After the training

- [ ] Send the handouts and this site link.
- [ ] Send the feedback form.
- [ ] Record the open questions and the follow-up actions.
- [ ] Give the support contact details to the customer.

!!! warning
    Do not use a live production database for the training. The trainees make test data that you cannot remove easily.
