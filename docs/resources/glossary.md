# Glossary

| Term | Meaning |
|---|---|
| ABM | Advance Bill of Materials. The early material list for the long-lead purchase. |
| Advance Bill | The Tekla PowerFab holding area for the material that the company buys before the detailing is complete. |
| AE | Automated Events. The module that runs a scheduled task without a logged-in user. |
| Bill of Lading | The shipping document for the truck driver. |
| CMB | The Combining module and its job type. |
| Combine | The function that fits many short pieces into one raw length. |
| Cut List | The batch of cuts for one machine operator. |
| Drop | The remnant that is left after a cut. |
| Global Edit | The function that changes one field on many selected rows. |
| Heat Number | The mill code for one batch of steel. It gives the material traceability. |
| IFC | Industry Foundation Classes. The open model exchange format. |
| JOBSUM | The report that shows the material that one job used. |
| KISS | A text material list format for import. |
| Labor Standard | The time value that Tekla PowerFab uses to calculate the man-hours. |
| Lot | A group of assemblies for the erection sequence. |
| Mult | The multiple-length combine calculation. |
| NC File | The machine file for a saw, a drill line or a plasma table. |
| Nest | The plate combine calculation. |
| PDC | The Production Control module and its job type. |
| PFXT | The Tekla PowerFab eXchange transfer file. |
| PO | Purchase Order. The external order to the supplier. |
| PRJ | The Project Management job type. |
| Requisition | The internal material request. |
| RFI | Request For Information. The formal question to the engineer or the client. |
| Route | The path of one piece through the shop stations. |
| Sequence | A group of assemblies for the fabrication order. |
| S/G/S | Shapes/Grades/Sizes. The global material database. |
| SOV | Schedule of Values. The invoice breakdown for the contract. |
| Station | One work point in a route, for example Saw or Welding. |
| TFS | Taken From Stock. The record of the material that a job consumed. |
| Transmittal | The formal document that sends drawings or files to another firm. |
| UDA | User-Defined Attribute. A custom field from the 3D model. |
| Work Package | A group of assemblies that the shop releases together. |
