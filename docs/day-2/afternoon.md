# Day 2 — Afternoon Session

- **Topic:** Estimodeling, pricing and labor
- **Chapters:** 3.2 thru 3.4

## 1. Estimodeling and importing (Chapter 3.2)

1. Go to **File > Import > Estimating > IFC**.
2. Select the IFC file.
3. Map the shapes and the grades in the **Translate Shapes/Grades** window.
4. Click OK to import the material.
5. Look at the model through the Trimble Connect integration.

!!! danger
    Examine the shape map and the grade map before you click OK. The software keeps the last map that you saved. A wrong saved map gives wrong shapes with no error message.

## 2. Combining and job-specific pricing (Chapters 3.2.3 thru 3.2.4)

1. Do a **Combine** run in the estimate with **Mult** and **Nest**.
2. Show the results.
3. Open **Job-Specific Pricing Maintenance** and change one material price for this bid only.

!!! info
    A combine run in an estimate does not reserve inventory. It only calculates the most efficient material purchase for the bid.

## 3. Labor (Chapter 3.3)

Use the **Tell, Show, Do** method for the labor hierarchy. The trainees must understand this flow:

**Labor Codes > Labor Groups > Labor Operations > Labor Standards**

1. Select one line item.
2. Open the **Labor Diagnostics** screen.
3. Show how the software calculates the total man-hours.
4. Apply one **Manual Override** to force a specific time.

## 4. Proposals and exercises (Chapters 3.2.7 and 3.4)

1. Open **Proposal Setup** and set the layout.
2. Make a formal bid document for the client.
3. Let the trainees do the exercises at the end of Chapter 3.
