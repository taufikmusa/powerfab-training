# Day 2 — Morning Session

- **Topic:** Estimating setup and manual takeoffs
- **Chapters:** 3.0 thru 3.1.3

## 1. Estimating maintenance (Chapter 3.0)

The software needs the shop capabilities and the shop costs before the first estimate.

1. Go to **Maintenance > Estimating**.
2. Open **Fabricator Information**. Set the maximum saw dimensions, the auto clip-angles and the shop efficiency.
3. Open **Labor Rates** and set the rates.
4. Open **Cleaning Maintenance** and set the cleaning methods.
5. Open **Paint Maintenance**. Make one paint system with a primer and a topcoat.

## 2. Manual takeoff entry (Chapter 3.1)

1. Open the **Estimating** module.
2. Click **Add** to make a new job.
3. Show the Input Fields: Shape, Dimensions, Length, Grade and Labor Code.
4. Let the trainees add ten items by hand.

!!! tip
    A manual takeoff shows how the input fields work. The trainees then understand the imported data on the afternoon of Day 2.

## 3. Accessories, assemblies and parametric assemblies (Chapters 3.1.1 thru 3.1.3)

### 3.1 Accessories

1. Make one standard item that the shop uses many times, for example a web stiffener.
2. Link the item to a beam size.

### 3.2 Assemblies

1. Group more than one piece under one main mark, for example a roof frame.
2. Save the assembly.

### 3.3 Parametric assemblies

Use this function for miscellaneous steel.

1. Make an assembly with variables and formulas.
2. Calculate the angle size from the centre-to-centre span.
3. Test the assembly with two different spans.
