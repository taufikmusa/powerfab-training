# Day 5 — Morning Session

- **Topic:** Inventory control and documentation
- **Chapter:** 8

## 1. Inventory and Inventory History (Chapters 8.0 thru 8.0.2)

Explain the difference first:

- **Inventory** shows the available material and the reserved material.
- **Inventory History** shows the material that a job used. The software calls this material Taken From Stock (TFS).

Run these two reports:

1. The **AUDIT** report for a physical stock count.
2. The **JOBSUM** report for the material that one job used.

## 2. Valuation (Chapter 8.0.3)

Show the accounting trainees and the management trainees how to pull a valuation.

1. Run the valuation **By Date/Time**.
2. Run the valuation **By Date**.
3. Run the valuation **By Archive**.

!!! tip
    The By Archive valuation gives a fast snapshot for the end of the month.

## 3. Heat documents and manual combine (Chapters 8.0.4 thru 8.0.5)

### 3.1 Heat documents

1. Open **Check Heat Documents** to find the missing paperwork.
2. Attach the PDF file.
3. Link the PDF file to the heat number in **Inventory**.

### 3.2 Manual combine mode

1. Turn on **Manual Combine Mode**.
2. Remove one item from a combined length.
3. Add the item back.

!!! info
    Use manual combine mode only when the standard requisition combine gives a bad result. The standard combine is correct for most jobs.
