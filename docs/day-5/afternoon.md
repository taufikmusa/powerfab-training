# Day 5 — Afternoon Session

- **Topic:** Automated events and workflow review
- **Chapters:** 9 and 4.12

## 1. Automated events (Chapters 9.0 thru 9.3)

The **Automated Events** module runs a task without a logged-in user. It needs the Remote Server service.

### 1.1 Report events

1. Open the **Automated Events** module.
2. Make a new report event.
3. Set the schedule, for example one time each week.
4. Select the report, for example the overdue RFI report or the shipping summary report.
5. Save the report to a network folder or send it to the project managers.

### 1.2 Email settings

1. Open **Outgoing Email Settings** and enter the SMTP data.
2. Set up the failure notifications. The administrator then knows when a task fails.

!!! warning
    An automated event does not run when the Remote Server service is off. Make sure that the service starts with the server.

## 2. Full workflow review (Chapter 4.12)

1. Go back to the **Project Management** module.
2. Open the **Project Summary Reports**.
3. Show how the five days come together in one report: Estimating, Purchasing, Production and Shipping.

## 3. Questions and practice

Give the last hours to the trainees.

1. Let each trainee use the sandbox database.
2. Ask each trainee to run one job from an estimate to a shipping ticket.
3. Answer the questions.

    The [Implementation](../implementation/index.md) exercise gives a full 18-step path for this practice.
