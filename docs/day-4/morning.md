# Day 4 — Morning Session

- **Topic:** Cut lists, work packages and piece tracking
- **Chapters:** 7.0 thru 7.3

## 1. Cut lists and processing (Chapter 7.0)

Explain how the software turns combined material into a cutlist for the shop.

### In Tekla PowerFab Office

1. Go to **Review > Cut Lists**.
2. Make a new cutlist and save it.
3. Use the **Prioritization** tool to set the work order for the shop floor.
4. Print the cutlist report.

!!! warning
    New users often go to **Dashboards > Cut List Management**. That screen manages an existing cutlist. Use **Review > Cut Lists** to make a new cutlist.

### In Tekla PowerFab Go

1. Log in to Tekla PowerFab Go.
2. Tap **Cut Lists** and open the cutlist.
3. Select a heat number.
4. Process the cut.
5. Enter the drop location for the remnant.

## 2. Work package management (Chapter 7.2)

1. Open the **Work Package Management** dashboard.
2. Release one package to the shop floor. The operators then see it.
3. Put one package on hold.

## 3. Piece tracking (Chapter 7.3)

The piece tracking function moves material through the stations and the routes from Day 3.

### In Tekla PowerFab Office

1. Open the piece tracking screen.
2. Track one assembly through one station.

### In Tekla PowerFab Go

1. Tap **Production Tracking**.
2. Use **Add Batch** to move a full work package through a station.
3. Repeat the task for the welding station.

Show the result in two places:

- The **Production Status** screen in the office.
- The 3D model colours in Trimble Connect.

!!! warning
    New users often open **Production Status** to change a station setting. Use **Fabrication Maintenance** for the station setup. **Production Status** shows the progress only.
