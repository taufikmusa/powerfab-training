# Day 4 — Afternoon Session

- **Topic:** Quality control, shipping and change management
- **Chapters:** 7.4 thru 7.6

## 1. Inspection and quality control (Chapter 7.4)

The **Inspection** module can test assemblies, parts, equipment and employees.

1. Make one test in the office.
2. Do the test in Tekla PowerFab Go.
3. Fail one piece, for example for a missing cope.
4. Attach a photo from the mobile device.
5. Show that the failed piece stops the piece tracking and the shipping.
6. Do a follow-up test to pass the piece.

!!! tip
    A piece can have an inspection requirement without a route. Examine the main mark if the station quantity does not agree with the cutlist quantity.

## 2. Load tracking and shipping (Chapter 7.5)

### Basic shipping

1. Go to **Production Control > Load Tracking**.
2. Make a new load and assign a trailer.
3. Add the material to the load.
4. Make the shipping ticket.
5. Do the same task in Tekla PowerFab Go.

### Shipping calendar

1. Open the **Shipping Calendar** dashboard.
2. Drag one load to a different day.

### Intermediate shipping

1. Make a shipping route to a third party, for example a galvanizer.
2. Send the material to the third party first. The material then goes to the job site.

!!! warning
    Tekla PowerFab Office does not stop a load with incomplete stations. Tekla PowerFab Go 2026 does stop it. Make sure that the office user examines the route status before shipment.

## 3. Change management (Chapter 7.6)

1. Import a revised PFXT file or XML file into the active job.
2. Open the **Change Summary Screen**.
3. Find the changes, for example a modified length or a new part.
4. Open the **Model Comparison** tool in Trimble Connect to see the old assembly and the new assembly.
5. Accept, prevent or save each change for later. Use the shop progress to decide.
